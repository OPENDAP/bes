# Deep Dives

One file per investigation, named `<slug>.md`, written by `/deep-dive`. Each starts
with the date and the question that prompted it, so a stale note (code has since
changed) is recognizable as possibly outdated rather than trusted as current fact.

Nothing else goes in this folder by hand-convention beyond that — the shape of each
note follows the question it's answering, not a fixed template.
